# 工具验证记录

日期：2026-11-19

测试环境：Python 3.12.14、PyMuPDF 1.26.6、fontTools 4.61.1。

使用临时生成的两页 PDF 和 Source Han Sans SC Regular／Bold 字体运行 `scripts/self_test.py`，未使用用户文档或网络服务。

已通过：

- 英文段落替换为可提取的中文，原句不残留；中文兼容字在断言时作 NFKC 等价比较。
- 常规及粗体字体嵌入，90° 页面与竖向文字方向保留。
- 原有矢量边框几何属性、图片尺寸／位置及测试图片像素摘要保留。
- 覆盖在替换文字上的 URI 链接、旋转页 URI 链接和跨页 GOTO 完整目标保留。
- 书签层级、页码及定位目标保留；PDF 对象号变化不视为目标变化。
- 输入文件 SHA-256 保持不变，输出另存。
- 无法容纳文字的文本框被拒绝，不生成截断或无限缩小字号的 PDF。
- 清单与带坐标提取正常；生成审校包后，账本状态仍为 pending。
- 项目、补丁与审校记录 JSON 模板均可解析；命令行帮助和 Python 语法检查通过。

本测试验证工具在合成样例上的行为，不代替实际项目的全文翻译审校、复杂字体／公式测试及逐页视觉检查。原始图形缺失、OCR、页面映射、复杂混排和语义翻译由 SKILL.md 的对应流程处理。
