# 航空技术手册中的语境示例

这些例子来自本次流程的经验归纳。用于提示审校，不是无条件替换表。其他行业必须重建术语表。

| 英文／上下文 | 推荐含义 | 常见误译或注意点 |
| --- | --- | --- |
| Chaff / countermeasures | Chaff（箔条） | 不是碎屑 |
| Flare / countermeasures | Flare（热焰弹） | 不是襟翼或一般照明弹 |
| Flare / landing | Flare（拉平） | 不是“火焰”；与上一行不是同一译法 |
| Stores / weapons | Stores（外挂物） | 不是商店或存储 |
| Jettison | 抛弃／应急抛弃 | 不等同于武器发射 |
| Receiver / radio or radar | 接收机 | 不要套用空中加油的“受油机” |
| Interrogator / Transponder | 询问机／应答机 | 不能混为一体 |
| Bank Steering Bar | 横滚／坡度指引杆 | 不是银行指导杆 |
| Ground Track | 地面航迹 | 不等同于 Heading（航向） |
| Magnetic Variation | 磁差 | 不是磁场变化量 |
| Navigation Fix | 导航定位修正／定位点（按上下文） | 不是软件修复、固定小数点或固定位置 |
| Leg / flight plan | 航段 | 不是腿部动作 |
| Holding / navigation | 等待 | 不等同于静止不动 |
| Feedhorn Nutation | 馈源喇叭章动 | 与 Precession（进动）有区别 |
| Pave Spike Targeting Pod | Pave Spike（铺路长钉）瞄准吊舱 | 不是目标小组或跟踪单元 |
| Fire Control Radar | 火控雷达 | 避免笼统写成制导雷达 |
| Hot Start / engine | 超温起动 | 不是热启动计算机 |
| Light-off / engine | 点火 | 与指示灯熄灭无关 |
| Fuel Cell / aircraft | 燃油囊 | 不是电池 |
| PDI / aerial refueling | Pilot Director（受油引导）灯 | steady = 常亮，不是暗淡；指令灯表示应移动的方向 |
| Command Light / seat control | 控制权指示灯 | 灯亮表示该座舱拥有控制权，不是“装有指挥装置” |
| Master Arm / ARM | 武器总保险／解除保险 | 区别 SAFE、OFF、ARM，以及弹射座椅等不同对象 |
| FWD / AFT / OUTBD / INBD | 向前／向后／向外／向内 | 不可译成前轮驱动、输出或内板 |
| nm / distance | 海里 | 不可译成纳米 |
| kts / airspeed | 节 | 不可直接改为公里／小时；换算时明确说明 |
| mil / aiming angle | 密位 | 不是毫米 |
| arc minutes / coordinates | 角分 | 不是时间的分钟 |

关键参数必须回到原页核对，不能把本表中的任何数字当成新文档的标准。原文内部如出现度与迎角单位混写等疑问，应核对上下文并明确处理依据。
